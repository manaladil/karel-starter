# Karel the Robot

This is a robot named Karel, developed during in class COSC-10001 at TCU. 
Karel is a robot that can only run four commands. 


## How to run it 

Open the folder in IntelliJ and press the green button, or run.ps1 on Windows and run.sh on macOS

## What I learned 

I learned how to use IntelliJ, combined with GitHub, and how to be creative in programming.
